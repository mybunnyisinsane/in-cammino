IN CAMMINO — PILGRIMAGE ITALIAN PROTOTYPE

Open index.html locally in a browser, or upload the in-cammino folder to the existing GitHub Pages repository mybunnyisinsane/082772. Then visit:
https://mybunnyisinsane.github.io/082772/in-cammino/

Do not overwrite the repository's root index.html or Latin student files.

Features: 36 vocabulary entries across three themes, bidirectional flashcard-style study, three original Italian readings with click-to-gloss words, comprehension checks, and device-local progress tracking. No external dependencies or server required.

This is a first-pass curriculum prototype. The reading passages are original constructed learning texts, not historical citations or live trail advisories. Always consult official trail notices for actual walking conditions.
